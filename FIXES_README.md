## ✅ Что исправлено

### 🔊 Проблема 1: Звук не работает на мобильных устройствах

**До:**
```javascript
// ❌ Звук блокировался браузером
audio.play() → DOMException: play() request was interrupted
```

**После:**
```javascript
// ✅ Разблокировка через AudioContext
При первом клике:
  1. Инициализируется AudioContext
  2. Воспроизводится пустой буфер
  3. Предзагружается реальный звук
  4. Канал разблокирован → audio.play() работает автоматически
```

**Результат:**
- ✅ Работает на iOS Safari
- ✅ Работает на Android Chrome  
- ✅ Работает в PWA режиме
- ✅ Мгновенное воспроизведение (без задержек)

---

### 🔢 Проблема 2: Длинный номер заказа

**До:**
```
ORD-232359  (timestamp, нет пробелов, неудобно читать)
```

**После:**
```
ORD - 123456  (6 случайных цифр, с пробелами)
```

**Преимущества:**
- ✅ Короче и читабельнее
- ✅ Проще продиктовать по телефону
- ✅ Лучше смотрится в UI
- ✅ Вероятность коллизии: 1 к 900,000

**Примеры:**
```
ORD - 100000
ORD - 456789
ORD - 999999
```
