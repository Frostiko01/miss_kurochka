# Smart Hero Banner - Реализация

## Обзор
Реализован современный Smart Hero Banner, который автоматически заменил старую карточку пользователя ("Добро пожаловать" + имя + email + аватар) на главной странице `/home`.

## Что было сделано

### 1. Удалена старая карточка пользователя
- **Файл**: `app/home/page.tsx`
- **Удалено**: Секция "GREETING" с приветствием, именем пользователя, email и аватаром
- **Строки**: ~665-685

### 2. Создан Smart Hero Banner компонент
- **Файл**: `components/SmartHeroBanner.tsx`
- **Функциональность**:
  - Автоматическая загрузка популярных товаров из базы данных
  - Автоматическая смена баннеров каждые 5 секунд
  - Поддержка свайпов и кликов для навигации
  - Анимации: Fade, Slide, Spring
  - Glassmorphism эффекты
  - Адаптивный дизайн

- **Особенности дизайна**:
  - Высота: 200px
  - Скругления: 24px (через класс `surface`)
  - Красные фирменные акценты (#ff4d00)
  - Большие фотографии блюд
  - Градиентные оверлеи для читаемости текста
  - Premium Food Delivery UI стиль

### 3. Создан API для автоматической генерации баннеров
- **Файл**: `app/api/smart-banner/route.ts`
- **Эндпоинт**: `GET /api/smart-banner`

- **Приоритеты отбора товаров**:
  1. Самые заказываемые за последние 7 дней (из `PopularItemsStats`)
  2. Самые продаваемые за 30 дней (из `PopularItemsStats`)
  3. Комбо с акциями (со старой ценой)
  4. Новинки (`isNew = true`)
  5. Избранные (`isFeatured = true`)
  6. Случайные активные товары (если ничего не найдено)

- **Возвращает**:
  ```json
  {
    "success": true,
    "banners": [
      {
        "id": "uuid",
        "type": "menu_item" | "combo",
        "name": "Название",
        "description": "Описание",
        "image": "url",
        "price": 250,
        "oldPrice": 300,
        "discount": 17,
        "badge": "Популярное" | "Новинка" | "Хит"
      }
    ]
  }
  ```

### 4. Админ-панель для управления

- **Настройки**:

  - ✅ Фильтры:

    - Показывать только акции
    - Показывать только комбо
  - ✅ Превью первых 3 баннеров
  - ✅ Кнопка "Обновить превью"

## Автоматическая генерация

### Использование изображений из базы данных
- ✅ НЕ хранит отдельные фотографии
- ✅ Автоматически берет изображения из `MenuItemImage` (isPrimary = true)
- ✅ Для комбо использует `ComboOffer.imageUrl`
- ✅ При изменении фото блюда — баннер автоматически обновляется

### Автоматический выбор товаров
- ✅ Каждые 5 секунд (по умолчанию) меняется баннер
- ✅ API пересчитывает популярность при каждом запросе
- ✅ Использует реальную статистику из таблицы `PopularItemsStats`
- ✅ Если товар закончился (`isAvailable = false`) — исключается автоматически

### Обработка акций
- ✅ Если есть `oldPrice` — показывает процент скидки
- ✅ Автоматически вычисляет: `discount = ((oldPrice - price) / oldPrice) * 100`
- ✅ Визуально выделяет: старая цена зачеркнута, новая цена крупная
- ✅ Бейдж со скидкой: "−17%" на оранжевом фоне

## Интеграция

### Как добавлен в проект
```tsx
// app/home/page.tsx
import SmartHeroBanner from "@/components/SmartHeroBanner";

// Внутри компонента:
<SmartHeroBanner onItemClick={(id, type) => {
  if (type === 'menu_item') {
    const item = allMenuItems.find(i => i.id === id);
    if (item) setDetailItem(item);
  } else {
    const combo = [...combos, ...miniCombos].find(c => c.id === id);
    if (combo) setSelectedCombo(combo);
  }
}} />
```

### API интеграция
```typescript
// Получение баннеров
const res = await fetch('/api/smart-banner');
const data = await res.json();
// data.banners содержит массив готовых баннеров
```

## База данных

### Используемые таблицы
1. **PopularItemsStats** - статистика заказов
   - `menuItemId` - ID товара
   - `orderCount` - количество заказов
   - `quantitySold` - количество проданных единиц
   - `date` - дата статистики

2. **MenuItem** - товары
   - `id`, `name`, `description`
   - `isNew`, `isFeatured`, `isActive`

3. **MenuItemImage** - изображения товаров
   - `menuItemId`, `imageUrl`
   - `isPrimary` - главное фото

4. **MenuItemSize** - размеры и цены
   - `menuItemId`, `price`

5. **ComboOffer** - комбо-предложения
   - `id`, `name`, `price`, `oldPrice`
   - `imageUrl`, `isActive`

## Настройка через админку

### Как настроить
1. Перейти в `/admin/smart-banner`
2. Включить Smart Banner (toggle)
3. Установить время автопрокрутки (3-10 сек)
4. Установить количество баннеров (1-10)
5. Выбрать фильтры (опционально)
6. Нажать "Сохранить настройки"
7. Проверить превью

### Хранение настроек
- Таблица: `SystemSetting`
- Ключ: `smart_banner`
- Значение: JSON с настройками

```json
{
  "enabled": true,
  "autoRotateSeconds": 5,
  "maxBanners": 5,
  "minOrderCount": 5,
  "showPopularOnly": false,
  "showPromotionsOnly": false,
  "showCombosOnly": false
}
```
