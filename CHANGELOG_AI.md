# Changelog - ИИ-Помощник с доступом к БД

## 🎉 Что добавлено

### Основной функционал

✅ **ИИ-помощник с доступом к базе данных PostgreSQL**
- Интеграция OpenAI GPT-4o-mini с Function Calling
- Прямой доступ к БД через Prisma ORM
- 4 функции для получения данных:
  - `get_menu_items` - меню с фильтрацией
  - `get_combo_offers` - комбо-предложения
  - `get_additional_offers` - дополнительные предложения
  - `get_branches` - информация о филиалах

## 🔧 Технические детали

### Стек технологий
- **AI:** OpenAI GPT-4o-mini
- **Database:** PostgreSQL + Prisma ORM
- **Backend:** Next.js API Routes
- **Frontend:** React + TypeScript

### Архитектура
```
Клиент (AiChatModal.tsx)
    ↓
POST /api/ai/chat
    ↓
OpenAI GPT-4o-mini + Function Calling
    ↓
Prisma → PostgreSQL
    ↓
Ответ с актуальными данными
```

### Переменные окружения
```env
OPEN_AI="sk-your-openai-api-key"
DATABASE_URL="postgresql://..."
```

## 📊 Возможности ИИ

### Что умеет ИИ-помощник:

1. **Информация о меню**
   - Актуальные цены всех блюд
   - Размеры порций и их стоимость
   - Состав и ингредиенты
   - Модификаторы (добавки) с ценами

2. **Фильтрация и поиск**
   - По категории (бургеры, курица, напитки)
   - По цене (до X сом)
   - По типу (вегетарианское, веганское)
   - По уровню остроты

3. **Рекомендации**
   - Персонализированные советы
   - Учет бюджета клиента
   - Популярные блюда
   - Выгодные комбо

4. **Комбо-предложения**
   - Список всех комбо
   - Состав каждого комбо
   - Сравнение цен (комбо vs отдельно)
   - Информация о скидках

5. **Информация о ресторане**
   - Адреса филиалов
   - Телефоны для заказа
   - Минимальная сумма заказа
   - Среднее время приготовления

## 🚀 Как использовать

### Для пользователей
1. Откройте сайт
2. Нажмите кнопку "ИИ Поддержка" (правый нижний угол)
3. Задайте вопрос о меню, ценах, доставке

### Для разработчиков
```bash
# 1. Добавьте API ключ в .env
OPEN_AI="sk-your-key"

# 2. Проверьте работу
npx tsx scripts/test-ai-chat.ts

# 3. Запустите dev-сервер
npm run dev
```

## 💰 Стоимость

### OpenAI GPT-4o-mini
- Входные токены: ~$0.15 за 1M токенов
- Выходные токены: ~$0.60 за 1M токенов

### Средний запрос
- ~500 токенов (вход + выход)
- **Стоимость: $0.0003** (0.03 цента)

### Прогноз на месяц
- 10,000 запросов = **$3**
- 100,000 запросов = **$30**

## 🐛 Известные ограничения

1. **Языковая модель**
   - Может иногда давать неточные ответы
   - Требует мониторинга качества

2. **Производительность**
   - Время ответа: 1-3 секунды
   - Зависит от нагрузки OpenAI API

3. **Стоимость**
   - Растет с количеством запросов
   - Требует мониторинга бюджета

4. **Данные**
   - Качество ответов зависит от полноты БД
   - Требует актуализации данных
