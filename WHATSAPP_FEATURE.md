## 🔨 Как добавить номер WhatsApp в филиал

### Через админ-панель:

1. Откройте: `/admin/branches`
2. Выберите филиал
3. Найдите поле "Номер WhatsApp"
4. Введите номер в формате: `+996700123456`
5. Сохраните

---

### Через SQL:

```sql
-- Обновить номер WhatsApp для филиала
UPDATE branches 
SET whatsapp_number = '+996700123456'
WHERE name = 'Бишкек Центр';

-- Проверить какие филиалы имеют WhatsApp
SELECT name, phone, whatsapp_number 
FROM branches 
WHERE whatsapp_number IS NOT NULL;
```

---

### Через API (если нужно):

```typescript
// PUT /api/admin/branches/:id
{
  "whatsappNumber": "+996700123456"
}
```

## 📞 FAQ

### Q: Можно ли использовать один номер WhatsApp для всех филиалов?

**A:** Да, просто заполните одинаковый номер для всех филиалов:
```sql
UPDATE branches SET whatsapp_number = '+996700123456';
```

---

### Q: Что если номер WhatsApp занят или недоступен?

**A:** WhatsApp покажет ошибку "Номер не зарегистрирован в WhatsApp". Убедитесь что номер:
- Зарегистрирован в WhatsApp
- Активен (не заблокирован)
- Указан в правильном формате (+996...)

---

### Q: Нужно ли WhatsApp Business?

**A:** Нет, подойдёт обычный WhatsApp. Но WhatsApp Business даёт преимущества:
- Автоответы
- Быстрые ответы
- Каталог товаров
- Статистика сообщений

---

### Q: Как изменить текст сообщения?

**A:** Отредактируйте функцию `getWhatsAppLink()` в файлах:
- `app/orders/[id]/page.tsx`
- `app/orders/[id]/receipt/page.tsx`

---

### Q: Работает ли на iOS?

**A:** Да, на iOS 8+ WhatsApp открывается корректно. Убедитесь что:
- WhatsApp установлен
- Формат ссылки: `https://wa.me/число` (без символов)
