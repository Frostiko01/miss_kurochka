# Тест очистки корзины при выходе

## Шаги для тестирования

### 1. Подготовка
1. Запустите приложение: `npm run dev`
2. Откройте браузер и перейдите на `http://localhost:3000`
3. Войдите в систему (или зарегистрируйтесь)

### 2. Тестирование функциональности

#### Сценарий 1: Очистка корзины при выходе с десктопа
1. Добавьте несколько товаров в корзину
2. Проверьте, что счётчик корзины показывает количество товаров
3. Нажмите на иконку профиля в правом верхнем углу
4. Выберите "Выйти из аккаунта"
5. **Ожидаемый результат:** Выход выполнен, редирект на страницу входа

#### Сценарий 2: Проверка очистки после повторного входа
1. Войдите снова с теми же учётными данными
2. Проверьте корзину
3. **Ожидаемый результат:** Корзина пустая, счётчик показывает 0

#### Сценарий 3: Очистка корзины при выходе с мобильного
1. Откройте сайт в мобильном представлении (DevTools, responsive mode)
2. Добавьте товары в корзину
3. Откройте боковое меню (☰)
4. Нажмите "Выйти из аккаунта"
5. **Ожидаемый результат:** Выход выполнен, корзина очищена

#### Сценарий 4: Очистка из профиля
1. Войдите и добавьте товары в корзину
2. Перейдите на страницу `/profile`
3. Нажмите кнопку "Выйти из аккаунта" внизу страницы
4. **Ожидаемый результат:** Выход выполнен, корзина очищена

### 3. Проверка API напрямую

Вы можете проверить API очистки корзины напрямую:

```bash
# Получить текущую корзину (требуется авторизация)
curl -X GET http://localhost:3000/api/cart \
  -H "Cookie: your-session-cookie"

# Очистить корзину (требуется авторизация)
curl -X DELETE http://localhost:3000/api/cart \
  -H "Cookie: your-session-cookie"
```

### 4. Проверка базы данных

Если у вас есть доступ к базе данных:

```sql
-- Проверить текущие позиции в корзине пользователя
SELECT ci.* 
FROM "CartItem" ci
JOIN "Cart" c ON c.id = ci."cartId"
JOIN "User" u ON u.id = c."userId"
WHERE u.email = 'test@example.com';

-- После выхода эта таблица должна быть пустой для данного пользователя
```

## Возможные проблемы

### Корзина не очищается
**Причина:** Возможно, используется старый `signOut` вместо `signOutWithCartCleanup`

**Решение:** Убедитесь, что компонент импортирует и использует `signOutWithCartCleanup`:
```typescript
import { signOut } from 'next-auth/react'
import { signOutWithCartCleanup } from '@/lib/cart-utils'

// Неправильно:
onClick={() => signOut({ callbackUrl: '/' })}

// Правильно:
onClick={() => signOutWithCartCleanup(signOut, '/')}
```

### Ошибка 401 при очистке корзины
**Причина:** Сессия уже была закрыта до вызова API очистки

**Решение:** Проверьте порядок вызовов в `signOutWithCartCleanup` - очистка должна идти **до** выхода

### Корзина очищается слишком медленно
**Причина:** Медленное соединение с базой данных

**Решение:** Это нормально, функция ждёт завершения очистки перед выходом для гарантии успешного удаления

## Резюме

Функция автоматической очистки корзины при выходе успешно реализована во всех клиентских компонентах. При выходе пользователя из системы:

1. ✅ Корзина очищается на сервере (DELETE /api/cart)
2. ✅ Пользователь выходит из системы
3. ✅ При следующем входе корзина пустая
4. ✅ Работает на десктопе и мобильных устройствах
5. ✅ Работает из всех точек выхода (меню, профиль, главная страница)
