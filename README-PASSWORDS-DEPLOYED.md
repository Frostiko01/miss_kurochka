### 2️⃣ Обновить пароли в Production БД

**⚠️ ВАЖНО:** Код уже на production, но пароли в БД еще не обновлены!

У вас есть 3 варианта:

#### Вариант A: SSH на сервер Timeweb (ЛУЧШИЙ)

```bash
# 1. Подключитесь к серверу
ssh user@your-server

# 2. Перейдите в директорию проекта
cd /path/to/miss-kurochka

# 3. Обновите код
git pull origin main

# 4. Запустите скрипт
npx tsx scripts/set-branch-password.ts
```

#### Вариант B: Локально с Production DATABASE_URL (БЫСТРЫЙ)

**На Windows (PowerShell):**
```powershell
.\scripts\update-production-passwords.ps1 -ProductionUrl "postgresql://user:pass@host:5432/db"
```

**На Linux/Mac (Bash):**
```bash
PRODUCTION_DATABASE_URL="postgresql://user:pass@host:5432/db" ./scripts/update-production-passwords.sh
```

📝 **Где взять Production DATABASE_URL:**
- Откройте панель Timeweb
- Перейдите: App Platform → Miss Kurochka → Переменные окружения
- Найдите `DATABASE_URL`
- Скопируйте значение

#### Вариант C: Вручную

```bash
# 1. Сохраните текущий .env
cp .env .env.backup

# 2. Откройте .env и временно замените DATABASE_URL на production

# 3. Запустите скрипт
npx tsx scripts/set-branch-password.ts

# 4. Верните .env обратно
cp .env.backup .env
```

➡️ См. раздел "1️⃣ Дождаться автодеплоя на Timeweb" выше

➡️ Запустите скрипт на production БД (см. раздел 2️⃣)

➡️ Проверьте, что скрипт был запущен именно на **production БД**, а не на локальной

### База данных недоступна
➡️ Проверьте `DATABASE_URL` в переменных окружения Timeweb
➡️ Убедитесь, что БД PostgreSQL запущена
