📱 Как проверить на телефоне

  • Android: Откройте сайт в Chrome → Меню → "Добавить на главный экран"
  • iOS: Откройте сайт в Safari → Поделиться → "Добавить на экран «Домой»"
  • Иконка должна отображаться с белым фоном без обрезания углов
  • Если видна старая иконка: удалите её → очистите кэш → добавьте снова
