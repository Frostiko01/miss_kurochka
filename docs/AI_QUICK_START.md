# ИИ-Помощник - Быстрый старт

## ⚡ За 5 минут

### 1. Получите API ключ OpenAI
```
https://platform.openai.com/api-keys
```

### 2. Добавьте в .env
```env
OPEN_AI="sk-ваш-ключ"
```

### 3. Проверьте работу
```bash
npx tsx scripts/test-ai-chat.ts
```

### 4. Готово! 🎉
Откройте сайт и нажмите кнопку "ИИ Поддержка"

## 🧪 Тестовые запросы

Попробуйте спросить у ИИ:

✅ "Сколько стоит Чикен Бургер?"
✅ "Что у вас есть вегетарианского?"
✅ "Покажи комбо до 500 сом"
✅ "Какие добавки можно выбрать?"
✅ "Где ваши филиалы?"

## 🔧 Что делает ИИ?

1. **Получает вопрос** от клиента
2. **Анализирует** что нужно найти
3. **Запрашивает данные** из PostgreSQL
4. **Формирует ответ** с актуальной информацией
5. **Отправляет** клиенту

## 📊 Доступные данные

- ✅ Меню (цены, размеры, состав)
- ✅ Комбо-предложения
- ✅ Модификаторы (добавки)
- ✅ Дополнительные предложения
- ✅ Филиалы (адреса, телефоны)

## 💰 Стоимость

OpenAI GPT-4o-mini:
- ~$0.15 за 1M входных токенов
- ~$0.60 за 1M выходных токенов

Средний запрос: ~500 токенов = $0.0003 (0.03 цента)

## 🚨 Важно

- Храните API ключ в `.env` (не коммитьте!)
- Проверяйте актуальность данных в БД
- Мониторьте использование токенов OpenAI
