# ИИ-Помощник Miss Kurochka - Руководство

## 📋 Обзор

ИИ-помощник Miss Kurochka - это интеллектуальный чат-бот с прямым доступом к базе данных ресторана. Он помогает клиентам:
- Узнавать актуальные цены и состав блюд
- Получать персонализированные рекомендации
- Находить информацию о комбо-предложениях
- Получать данные о филиалах и доставке

## 🚀 Быстрый старт

### 1. Настройка переменных окружения

Добавьте в `.env`:
```env
OPEN_AI="sk-your-openai-api-key"
DATABASE_URL="postgresql://user:password@localhost:5432/miss_kurochka"
```

### 2. Установка зависимостей

```bash
npm install openai @prisma/client
```

### 3. Проверка работы

```bash
# Тест доступа к БД
npx tsx scripts/test-ai-chat.ts

# Запуск dev-сервера
npm run dev
```

### 4. Использование в интерфейсе

На главной странице нажмите кнопку "ИИ Поддержка" в правом нижнем углу.

## 🔧 Технические детали

### Архитектура

```
Клиент (AiChatModal.tsx)
    ↓
POST /api/ai/chat
    ↓
OpenAI GPT-4o-mini + Function Calling
    ↓
Функции доступа к БД (Prisma)
    ↓
PostgreSQL
    ↓
Ответ с актуальными данными
```

### Доступные функции

#### 1. get_menu_items
Получение блюд из меню с фильтрацией.

**Параметры:**
- `category` (string, optional) - Категория блюд
- `isVegetarian` (boolean, optional) - Только вегетарианские
- `maxPrice` (number, optional) - Максимальная цена

**Возвращает:**
```typescript
{
  id: string
  name: string
  description: string
  category: string
  sizes: Array<{
    name: string
    price: number
    weight: number
  }>
  isVegetarian: boolean
  isVegan: boolean
  spicyLevel: number
  ingredients: string
  modifiers: Array<{
    groupName: string
    isRequired: boolean
    options: Array<{
      name: string
      priceDelta: number
    }>
  }>
}[]
```

#### 2. get_combo_offers
Получение комбо-наборов.

**Возвращает:**
```typescript
{
  id: string
  name: string
  description: string
  price: number
  oldPrice: number | null
  items: Array<{
    name: string
    quantity: number
  }>
}[]
```

#### 3. get_additional_offers
Получение дополнительных предложений (соусы, напитки).

**Параметры:**
- `category` (string, optional) - Категория

**Возвращает:**
```typescript
{
  id: string
  name: string
  description: string
  price: number
  category: string
}[]
```

#### 4. get_branches
Получение информации о филиалах.

**Возвращает:**
```typescript
{
  id: string
  name: string
  address: string
  phone: string
  city: string
  minOrderAmount: number | null
  averageCookingTime: number | null
}[]
```

## 💡 Примеры запросов

### Поиск по цене
**Клиент:** "Что у вас есть до 200 сом?"
**ИИ:** Вызывает `get_menu_items({ maxPrice: 200 })` и показывает доступные блюда

### Вегетарианские блюда
**Клиент:** "Есть ли вегетарианские блюда?"
**ИИ:** Вызывает `get_menu_items({ isVegetarian: true })` и перечисляет опции

### Информация о комбо
**Клиент:** "Какие комбо самые выгодные?"
**ИИ:** Вызывает `get_combo_offers()` и сравнивает цены

### Состав блюда
**Клиент:** "Что входит в Чикен Бургер?"
**ИИ:** Вызывает `get_menu_items({ category: "бургер" })` и показывает состав

### Модификаторы
**Клиент:** "Какие добавки можно выбрать к бургеру?"
**ИИ:** Показывает доступные модификаторы из БД с ценами

## 🎯 Лучшие практики

### Для разработчиков

1. **Всегда используйте актуальные данные из БД**
   - Не хардкодите цены в промпте
   - Используйте функции для получения данных

2. **Оптимизируйте запросы**
   - Используйте `take` для ограничения результатов
   - Добавляйте индексы в БД для часто запрашиваемых полей

3. **Обрабатывайте ошибки**
   - Проверяйте доступность БД
   - Логируйте ошибки функций

4. **Тестируйте регулярно**
   - Запускайте `test-ai-chat.ts` после изменений в схеме БД
   - Проверяйте работу функций вручную

### Для контент-менеджеров

1. **Поддерживайте актуальность данных**
   - Обновляйте цены в БД
   - Отмечайте неактивные блюда (`isActive: false`)

2. **Заполняйте описания**
   - Добавляйте подробные описания блюд
   - Указывайте ингредиенты и аллергены

3. **Используйте категории**
   - Правильно категоризируйте блюда
   - Это улучшает поиск ИИ

## 🔍 Отладка

### Проверка логов

```bash
# Логи OpenAI API
tail -f logs/ai-chat.log

# Логи Prisma
DEBUG="prisma:*" npm run dev
```

### Частые проблемы

**Проблема:** ИИ не находит блюда
**Решение:** Проверьте, что блюда активны (`isActive: true`)

**Проблема:** Неверные цены
**Решение:** Убедитесь, что у блюд есть активные размеры (`sizes.isActive: true`)

**Проблема:** Ошибка подключения к БД
**Решение:** Проверьте `DATABASE_URL` в `.env`

**Проблема:** Превышен лимит токенов OpenAI
**Решение:** Уменьшите `take` в запросах или увеличьте `max_tokens`

## 🔐 Безопасность

1. **Защита API ключей**
   - Никогда не коммитьте `.env`
   - Используйте переменные окружения

2. **Ограничение доступа**
   - Функции возвращают только публичные данные
   - Нет доступа к персональным данным пользователей

3. **Rate limiting**
   - Ограничьте количество запросов на пользователя
   - Используйте кэширование для частых запросов
