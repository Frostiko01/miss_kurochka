# Тестовые промпты для ИИ-помощника

## 📋 Категории тестов

### 1. Поиск по цене

```
✅ "Что у вас есть до 200 сом?"
✅ "Покажи самые дешевые блюда"
✅ "Что можно купить за 300 сом?"
✅ "Есть что-то в районе 150-250 сом?"
```

**Ожидаемое поведение:**
- Вызов `get_menu_items({ maxPrice: X })`
- Список блюд с ценами
- Упоминание размеров (если есть)

---

### 2. Фильтрация по типу

```
✅ "Есть ли вегетарианские блюда?"
✅ "Что у вас веганского?"
✅ "Покажи блюда без мяса"
✅ "Какие есть острые блюда?"
```

**Ожидаемое поведение:**
- Вызов `get_menu_items({ isVegetarian: true })` или аналог
- Список подходящих блюд
- Упоминание уровня остроты (если применимо)

---

### 3. Поиск по категории

```
✅ "Какие у вас есть бургеры?"
✅ "Покажи все блюда с курицей"
✅ "Что есть из напитков?"
✅ "Какие десерты у вас есть?"
```

**Ожидаемое поведение:**
- Вызов `get_menu_items({ category: "X" })`
- Список блюд из категории
- Цены и размеры

---

### 4. Информация о конкретном блюде

```
✅ "Сколько стоит Чикен Бургер?"
✅ "Что входит в состав Классического Бургера?"
✅ "Какие размеры у Картофеля фри?"
✅ "Есть ли аллергены в Цезаре?"
```

**Ожидаемое поведение:**
- Вызов `get_menu_items` с фильтром по названию
- Подробная информация о блюде
- Цены всех размеров
- Состав и ингредиенты

---

### 5. Модификаторы и добавки

```
✅ "Какие добавки можно выбрать к бургеру?"
✅ "Сколько стоит добавить сыр?"
✅ "Можно ли сделать бургер острым?"
✅ "Какие соусы у вас есть?"
```

**Ожидаемое поведение:**
- Вызов `get_menu_items` с включением модификаторов
- Или `get_additional_offers({ category: "соус" })`
- Список опций с ценами

---

### 6. Комбо-предложения

```
✅ "Какие у вас есть комбо?"
✅ "Покажи самое выгодное комбо"
✅ "Что входит в Комбо №1?"
✅ "Есть ли комбо с бургером и картошкой?"
```

**Ожидаемое поведение:**
- Вызов `get_combo_offers()`
- Список комбо с составом
- Сравнение цен (комбо vs отдельно)
- Упоминание скидки (если есть)

---

### 7. Рекомендации

```
✅ "Что посоветуете попробовать?"
✅ "Что самое популярное?"
✅ "Что взять на обед на двоих?"
✅ "Посоветуй что-то сытное и недорогое"
```

**Ожидаемое поведение:**
- Вызов `get_menu_items` или `get_combo_offers`
- Персонализированные рекомендации
- Учет бюджета (если указан)
- Упоминание популярных блюд

---

### 8. Информация о филиалах

```
✅ "Где ваши филиалы?"
✅ "Какой адрес ближайшего ресторана?"
✅ "Какой телефон для заказа?"
✅ "Какая минимальная сумма заказа?"
```

**Ожидаемое поведение:**
- Вызов `get_branches()`
- Список филиалов с адресами
- Контактная информация
- Условия доставки

---

### 9. Доставка и заказ

```
✅ "Как сделать заказ?"
✅ "Сколько стоит доставка?"
✅ "Как долго готовится заказ?"
✅ "Какие способы оплаты?"
```

**Ожидаемое поведение:**
- Информация из системного промпта
- Возможно вызов `get_branches()` для времени приготовления
- Объяснение процесса заказа

---

### 10. Комбинированные запросы

```
✅ "Посоветуй вегетарианское комбо до 400 сом"
✅ "Какие бургеры есть с курицей и сколько они стоят?"
✅ "Что можно взять на компанию из 4 человек на 2000 сом?"
✅ "Есть ли острые блюда с курицей до 300 сом?"
```

**Ожидаемое поведение:**
- Несколько вызовов функций
- Фильтрация по нескольким параметрам
- Комплексный ответ с расчетами

---

## 🚫 Негативные тесты

### Вопросы вне темы

```
❌ "Какая погода сегодня?"
❌ "Кто выиграл чемпионат мира?"
❌ "Как приготовить борщ?"
```

**Ожидаемое поведение:**
- Вежливый отказ
- Возврат к теме ресторана
- Предложение помощи по меню

---

### Несуществующие блюда

```
❌ "Сколько стоит пицца?"
❌ "Есть ли у вас суши?"
```

**Ожидаемое поведение:**
- Вызов функции поиска
- Сообщение об отсутствии
- Предложение альтернатив

---

### Некорректные запросы

```
❌ "asdfghjkl"
❌ "123456"
❌ "" (пустое сообщение)
```

**Ожидаемое поведение:**
- Просьба переформулировать
- Предложение помощи
- Примеры вопросов

---

## 📊 Метрики успешности

### Хороший ответ:
- ✅ Использует актуальные данные из БД
- ✅ Отвечает на вопрос полностью
- ✅ Указывает конкретные цены
- ✅ Предлагает альтернативы (если уместно)
- ✅ Краткий и понятный (3-5 предложений)

### Плохой ответ:
- ❌ "Уточните в меню" (вместо конкретной цены)
- ❌ Выдуманная информация
- ❌ Слишком длинный (>7 предложений)
- ❌ Не отвечает на вопрос
- ❌ Технические ошибки

## 🧪 Автоматизированное тестирование

Создайте скрипт для автоматической проверки:

```typescript
const testCases = [
  {
    prompt: "Сколько стоит Чикен Бургер?",
    expectedFunctions: ["get_menu_items"],
    shouldInclude: ["сом", "бургер"]
  },
  {
    prompt: "Какие комбо есть?",
    expectedFunctions: ["get_combo_offers"],
    shouldInclude: ["комбо", "сом"]
  }
]

// Запуск тестов
for (const test of testCases) {
  const response = await testAI(test.prompt)
  assert(response.functionsUsed.includes(test.expectedFunctions))
  assert(test.shouldInclude.every(word => response.reply.includes(word)))
}
```
