## Возможные проблемы и решения

### ❌ Проблема: Старая иконка всё ещё отображается на телефоне

**Причина:** Браузер кэширует старую версию иконки.

**Решение для Android:**
```
1. Удалите приложение с главного экрана
2. Chrome → Настройки → Конфиденциальность → Очистить данные
3. Закройте Chrome полностью (свайп в Recent Apps)
4. Откройте сайт снова → Добавьте на главный экран
```

**Решение для iOS:**
```
1. Удалите иконку с домашнего экрана (долгое нажатие → крестик)
2. Настройки → Safari → Очистить историю и данные
3. Закройте Safari полностью (свайп вверх в переключателе)
4. Откройте Safari → добавьте сайт на главный экран
```

### ❌ Проблема: Service Worker не обновляется

**Причина:** Браузер кэширует старый Service Worker.

**Решение:**
```
1. Откройте DevTools (F12)
2. Вкладка Application → Service Workers
3. Нажмите "Unregister" для старого SW
4. Перезагрузите страницу (Ctrl+Shift+R / Cmd+Shift+R)
5. Новый SW должен установиться автоматически
```

### ❌ Проблема: Иконки не загружаются (404)

**Причина:** Файлы не были загружены на сервер или неправильные пути.

**Решение:**
```
1. Проверьте что все иконки есть в папке public/
2. Убедитесь что Next.js скопировал их в .next/static/
3. После деплоя проверьте доступность:
   https://ваш-домен.com/icon-512.png?v=3
```
