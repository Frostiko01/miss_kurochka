# Настройка приватного ключа Finik

## Проблема

Ошибка `Failed to generate Finik signature` возникает из-за неправильного формата приватного ключа в файле `.env`.

## Решение

### Шаг 1: Запустите скрипт проверки

```bash
npx tsx scripts/test-finik-key.ts
```

Этот скрипт:
- ✅ Проверит все переменные окружения Finik
- ✅ Прочитает реальный ключ из `C:/FinikKeys/finik_private.pem`
- ✅ Протестирует генерацию подписи
- ✅ Создаст файл `finik_key_for_env.txt` с правильным форматом для `.env`

### Шаг 2: Обновите .env файл

1. Откройте созданный файл `finik_key_for_env.txt`
2. Скопируйте строку с `FINIK_PRIVATE_KEY="..."`
3. Замените текущую строку `FINIK_PRIVATE_KEY` в файле `.env`

### Шаг 3: Перезапустите сервер

```bash
# Остановите текущий сервер (Ctrl+C)
# Запустите заново
npm run dev
```

## Формат приватного ключа

Приватный ключ должен быть в формате:

```env
FINIK_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\nMIIEo...реальный_ключ...XYZ\n-----END RSA PRIVATE KEY-----"
```

**Важно:**
- Все переносы строк заменены на `\n`
- Ключ заключен в двойные кавычки
- Нет пробелов в начале или конце

## Проверка после настройки

После обновления `.env` файла:

1. Перезапустите сервер разработки
2. Попробуйте создать тестовый платеж
3. Проверьте логи - должно появиться:
   ```
   🔐 Generating Finik signature...
   ✅ Signature generated successfully
   ```

## Альтернативный способ (вручную)

Если скрипт не работает, можно настроить вручную:

1. Откройте файл `C:/FinikKeys/finik_private.pem` в текстовом редакторе
2. Скопируйте весь ключ (включая `-----BEGIN...` и `-----END...`)
3. Замените все переносы строк на `\n`
4. Оберните в двойные кавычки
5. Вставьте в `.env` как значение `FINIK_PRIVATE_KEY`

### Пример преобразования:

**Было (в .pem файле):**
```
-----BEGIN RSA PRIVATE KEY-----
MIIEogIBAAKCAQEA...
...строки ключа...
-----END RSA PRIVATE KEY-----
```

**Стало (в .env файле):**
```env
FINIK_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\nMIIEogIBAAKCAQEA...\n...строки ключа...\n-----END RSA PRIVATE KEY-----"
```

## Проверка окружения

Убедитесь, что все переменные Finik настроены:

```env
FINIK_ENV="prod"
FINIK_ACCOUNT_ID="dbee8f08-bce2-4565-b949-118a657df8d4"
FINIK_API_KEY="vXxDBgE1TMaL2L7Jif5hP7pqeepjxdzp1GGyAMmh"
FINIK_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\n...реальный_ключ...\n-----END RSA PRIVATE KEY-----"
```

## Безопасность

⚠️ **ВАЖНО:**
- Никогда не коммитьте `.env` файл в Git
- Файл `.env` уже добавлен в `.gitignore`
- Храните приватный ключ в безопасном месте
- Не делитесь ключом в публичных каналах

## Дополнительная диагностика

Если проблема сохраняется, проверьте логи при создании платежа:

```
🔐 Generating Finik signature...
Private key length: XXXX
Private key starts with: -----BEGIN RSA PRIVATE KEY-----
```

Если длина ключа меньше 1000 символов или начало неправильное - ключ настроен неверно.

## Поддержка

Если проблема не решается:
1. Проверьте формат ключа в файле `C:/FinikKeys/finik_private.pem`
2. Убедитесь, что используете правильный ключ (prod или beta)
3. Свяжитесь с технической поддержкой Finik для получения нового ключа
