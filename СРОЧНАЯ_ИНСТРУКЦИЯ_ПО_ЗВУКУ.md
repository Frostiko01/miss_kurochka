# 🔊 СРОЧНАЯ ИНСТРУКЦИЯ: Как включить звук уведомлений

## ⚠️ ВАЖНО: Звук не включается автоматически!

Звук **НЕ работает по умолчанию**. Нужно **вручную включить** кнопкой в интерфейсе.

---

## 📱 Пошаговая инструкция (2 минуты)

### Шаг 1: Откройте панель филиала на телефоне

Откройте в **Google Chrome** (или другом браузере):
```
https://ваш-домен.com/branch/signin
```

Войдите под логином и паролем филиала.

---

### Шаг 2: ОБЯЗАТЕЛЬНО тапните в экран

**ВАЖНО!** После входа **тапните пальцем** в любое место на экране.

```
┌─────────────────────────┐
│                         │
│    👆 ТАПНИТЕ СЮДА      │
│    (или в любое место)  │
│                         │
└─────────────────────────┘
```

Это нужно чтобы браузер разрешил воспроизведение звука.

---

### Шаг 3: Найдите кнопку динамика

В **правом верхнем углу** экрана найдите кнопку с иконкой динамика.

**ДО включения** она выглядит так:
```
🔇 (серая, перечёркнутый динамик)
```

---

### Шаг 4: НАЖМИТЕ на кнопку динамика

Тапните на кнопку динамика **один раз**.

**ПОСЛЕ включения** она должна стать:
```
🔊 (синяя/голубая, динамик со звуковыми волнами)
```

---

### Шаг 5: Разрешите звук в Chrome (если появится запрос)

**На Android Chrome** может появиться всплывающее окно:

```
┌────────────────────────────────┐
│ Разрешить воспроизведение      │
│ звука на этом сайте?           │
│                                │
│  [Запретить]  [Разрешить] ←👆  │
└────────────────────────────────┘
```

**ОБЯЗАТЕЛЬНО нажмите "Разрешить"!**

---

### Шаг 6: Проверьте что работает

1. Создайте тестовый заказ (с другого устройства или попросите кого-то)
2. Подождите 10-15 секунд
3. Должен зазвенеть звук 🔊
4. Появится оранжевая рамка вокруг нового заказа
5. Появится индикатор "1 новый"

**Если звук зазвенел - ВСЁ РАБОТАЕТ!** ✅

---

## 🔍 Если звук НЕ работает

### Проблема 1: Не тапнули в экран

**Решение:**
1. **Тапните пальцем** в любое место экрана
2. Выключите звук (нажмите кнопку динамика)
3. Включите звук снова (нажмите кнопку динамика)
4. Попробуйте создать тестовый заказ

---

### Проблема 2: Переключатель "Без звука" включен (iPhone)

**На iPhone** сбоку есть переключатель "Без звука".

**Решение:**
1. Найдите переключатель на **левой стороне** iPhone
2. Убедитесь что переключатель **ВЫКЛЮЧЕН**
3. Если видна оранжевая полоска = звук заблокирован
4. Передвиньте переключатель чтобы оранжевая полоска **исчезла**

---

### Проблема 3: Громкость телефона на минимуме

**Решение:**
1. Нажмите кнопку **увеличения громкости** на телефоне
2. Убедитесь что громкость **НЕ на нуле**
3. Рекомендуемая громкость: **70-80%**

**На Android:**
- Увеличивайте именно **громкость мультимедиа** (не звонка!)

---

### Проблема 4: Chrome блокирует звук

**Проверьте разрешения Chrome:**

**На Android:**
1. Настройки Chrome → Настройки сайтов
2. Найдите ваш домен
3. Проверьте что звук **разрешён**

**На iPhone/Safari:**
1. Настройки → Safari → Дополнения
2. Найдите ваш домен
3. Убедитесь что нет блокировок

---

### Проблема 5: Звуковой файл не найден

**Проверьте что файл существует:**

1. Откройте в браузере:
```
https://ваш-домен.com/uvedomlenie.mp3
```

2. Должен начать воспроизводиться звук

**Если показывает ошибку 404:**
- Файл отсутствует на сервере
- Свяжитесь с администратором

---

### Проблема 6: Деплой ещё не завершился

**Если только что задеплоили:**

Подождите **5-10 минут** чтобы изменения применились.

**Как проверить:**
1. Закройте приложение **полностью**
2. Откройте Chrome заново
3. Зайдите на сайт снова
4. Повторите инструкцию с Шага 1

---

## 🧪 Быстрая диагностика (для программистов)

### Откройте консоль браузера:

**На Android Chrome:**
1. Подключите телефон к компьютеру через USB
2. На компьютере откройте Chrome
3. Перейдите: `chrome://inspect`
4. Найдите ваше устройство → "Inspect"

**На iPhone Safari:**
1. Подключите iPhone к Mac
2. На Mac откройте Safari → Develop → [Ваш iPhone]
3. Выберите вкладку с сайтом

---

### Проверьте логи:

**После тапа в экран** должна появиться запись:
```
✅ Аудио разблокировано на мобильном устройстве
```

**Если этой записи НЕТ:**
- Разблокировка не сработала
- Попробуйте ещё раз тапнуть в экран

---

**При попытке воспроизведения** НЕ должно быть ошибок типа:
```
❌ DOMException: play() request was interrupted
❌ NotAllowedError: The play() request was interrupted
```

**Если такие ошибки ЕСТЬ:**
- Значит User Gesture не сработал
- Попробуйте перезагрузить страницу и тапнуть снова

## 💡 Дополнительные советы

### Совет 1: Держите вкладку активной

Звук работает только когда:
- ✅ Вкладка браузера **активна** (на переднем плане)
- ✅ Приложение **не в фоне**
- ✅ Экран **не заблокирован**

**Рекомендация:**
Держите панель филиала открытой на переднем плане телефона.

---

### Совет 2: Не закрывайте браузер

Если закрыли браузер (смахнули из списка приложений):
- Звук перестанет работать
- Придётся включать заново

---

### Совет 3: Проверяйте звук в начале смены

**Рекомендуется:**
1. В начале каждой смены
2. Открыть панель филиала
3. Тапнуть в экран
4. Включить звук кнопкой
5. Создать тестовый заказ для проверки

Это займёт 30 секунд, но сэкономит время позже.

---

### Совет 4: Зарядите телефон

Звук потребляет батарею.  
Держите телефон на зарядке во время смены.

---

## 🔄 Альтернативное решение: Desktop версия

**Если на телефоне не работает:**

Попробуйте открыть панель филиала на **компьютере**:
1. Откройте Chrome/Edge/Firefox на ПК
2. Зайдите на панель филиала
3. Кликните мышкой в любое место
4. Включите звук кнопкой

На десктопе звук работает **более стабильно**.

---

## 📞 Если ничего не помогло

### Вариант 1: Попробуйте другой браузер

**На Android:**
- Chrome (рекомендуется)
- Firefox
- Edge

**На iPhone:**
- Safari (рекомендуется)
- Chrome для iOS

---

### Вариант 2: Перезагрузите устройство

1. Полностью выключите телефон
2. Включите снова
3. Откройте браузер
4. Повторите инструкцию с Шага 1

---

### Вариант 3: Очистите кэш браузера

**На Android Chrome:**
1. Настройки Chrome
2. Конфиденциальность и безопасность
3. Очистить данные браузера
4. Выбрать "Кэш" и "Файлы cookie"
5. Очистить

**На iPhone Safari:**
1. Настройки → Safari
2. Очистить историю и данные
3. Подтвердить

После очистки повторите инструкцию с Шага 1.

---

### Вариант 4: Обратитесь к администратору

Если ничего не помогло, свяжитесь с администратором системы.

**Что сообщить:**
- Модель телефона (например: iPhone 13, Samsung Galaxy S21)
- Браузер и версия (Chrome 120, Safari 17, и т.д.)
- Что вы уже попробовали из инструкции
- Скриншот консоли браузера (если можете)
