# 📁 Файлы для деплоя на Timeweb App Platform

## 🎯 Основные файлы

### 1. 🐳 Dockerfile
**Назначение:** Конфигурация Docker-образа для production  
**Использование:** Автоматически используется Timeweb при деплое  
**Особенности:**
- Multi-stage сборка (3 этапа)
- Оптимизирован для Next.js 16
- Размер образа: ~200-300 MB
- Безопасность: непривилегированный пользователь

### 2. 📋 .dockerignore
**Назначение:** Исключение ненужных файлов из Docker-образа  
**Использование:** Автоматически используется при сборке  
**Исключает:**
- node_modules
- .env файлы
- .git, IDE файлы
- Документацию

### 3. ⚙️ next.config.ts
**Изменение:** Добавлен `output: 'standalone'`  
**Назначение:** Оптимизация для Docker  
**Результат:** Минимальный размер production-сборки

## 🎯 Быстрые ссылки

### Для начинающих:
1. Прочитайте [QUICK_START.md](./QUICK_START.md)
2. Проверьте [DEPLOY_CHECKLIST.md](./DEPLOY_CHECKLIST.md)
3. Деплойте!

### Для опытных:
1. Проверьте [Dockerfile](./Dockerfile)
2. Настройте переменные из [.env.production.example](./.env.production.example)
3. Деплойте!

### При проблемах:
1. Проверьте [DEPLOY_CHECKLIST.md](./DEPLOY_CHECKLIST.md) → Раздел "Частые ошибки"
2. Читайте [TIMEWEB_DEPLOY.md](./TIMEWEB_DEPLOY.md) → Раздел "Решение проблем"
3. Проверьте логи в панели Timeweb

## 📦 Что НЕ нужно коммитить в Git

- ❌ `.env` - локальные переменные
- ❌ `.env.docker` - для локального тестирования Docker
- ❌ `.env.local` - локальные переменные
- ❌ `node_modules/` - зависимости
- ❌ `.next/` - сборка Next.js

Все это уже в `.gitignore`!

## ✅ Что нужно закоммитить

- ✅ `Dockerfile` - конфигурация Docker
- ✅ `.dockerignore` - исключения для Docker
- ✅ `next.config.ts` - конфигурация Next.js (с `output: 'standalone'`)
- ✅ Вся документация (TIMEWEB_DEPLOY.md и т.д.)
- ✅ `.env.example` и `.env.production.example` - шаблоны
