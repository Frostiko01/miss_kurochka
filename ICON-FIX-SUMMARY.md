# ✅ Исправление PWA иконок — Краткая сводка

## Что было сделано

### 🎯 Проблема
Иконка Miss Kurochka при добавлении на главный экран телефона обрезалась некорректно — торчали красные части круглого логотипа.

### 🔧 Решение
Созданы новые иконки с белым padding:
- **15% отступ** для обычных иконок (iOS, Android)
- **20% отступ** для maskable иконок (Android adaptive icons)

## 📦 Созданные/Обновлённые файлы

### Новые файлы:
1. **`scripts/fix-pwa-icons.js`** — скрипт генерации иконок
2. **`scripts/README-PWA-ICONS.md`** — подробная документация
3. **`public/test-icons.html`** — страница визуальной проверки иконок

### Обновлённые файлы:
1. **`app/manifest.ts`** — пути к иконкам с версией `?v=3`
2. **`app/layout.tsx`** — мета-теги для иконок с версией `?v=3`
3. **`public/sw.js`** — обновлена версия Service Worker до `v1.0.1`
4. **`public/icon-512.png`** — новая иконка с padding ✨
5. **`public/icon-192.png`** — новая иконка с padding ✨
6. **`public/apple-icon.png`** — новая иконка с padding ✨
7. **`public/icon-maskable-512.png`** — новая maskable иконка ✨
8. **`public/icon-maskable-192.png`** — новая maskable иконка ✨

## 🚀 Как проверить

### В браузере (локально):
```bash
npm run dev
```
Откройте: http://localhost:3000/test-icons.html

### На телефоне:

#### Android (Chrome):
1. Откройте сайт в Chrome
2. Меню (⋮) → **"Добавить на главный экран"** или **"Install app"**
3. Проверьте иконку на главном экране

#### iOS (Safari):
1. Откройте сайт в Safari
2. Кнопка "Поделиться" 📤 (квадрат со стрелкой вверх)
3. **"Добавить на экран «Домой»"**
4. Проверьте иконку на главном экране

### 🔄 Если старая иконка всё ещё отображается:

**Android:**
```
1. Удалите приложение с главного экрана
2. Chrome → Настройки → Конфиденциальность → Очистить данные браузера
3. Закройте Chrome полностью
4. Откройте сайт снова → Добавьте на главный экран
```

**iOS:**
```
1. Удалите иконку с домашнего экрана (долгое нажатие → крестик)
2. Закройте Safari полностью (смахните вверх в переключателе приложений)
3. Откройте Safari снова → добавьте сайт на главный экран
```

## 🔄 Повторная генерация иконок

Если нужно обновить логотип в будущем:

```bash
# 1. Замените public/logo.png на новый логотип (500×500 px, круглый)
# 2. Запустите скрипт:
node scripts/fix-pwa-icons.js
```

Скрипт автоматически создаст все необходимые иконки с правильным padding.
