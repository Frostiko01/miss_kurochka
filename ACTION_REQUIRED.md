### ШАГ 3: Проверьте переменные окружения (5 минут)

1. **Откройте Timeweb → Ваше приложение → "Переменные окружения"**

2. **Найдите переменную `NEXT_PUBLIC_APP_URL`:**

   **Если она есть, проверьте значение:**
   ```
   ✅ ПРАВИЛЬНО: NEXT_PUBLIC_APP_URL=https://miss-kurochka.com
   ❌ НЕПРАВИЛЬНО: NEXT_PUBLIC_APP_URL=https://miss-kurochka.com/  (с trailing slash)
   ❌ НЕПРАВИЛЬНО: NEXT_PUBLIC_APP_URL=http://localhost:3000
   ```

   **Если неправильно:**
   - Исправьте на: `https://miss-kurochka.com`
   - Сохраните
   - Перезапустите приложение

   **Если переменной нет:**
   - Добавьте новую переменную:
     ```
     Название: NEXT_PUBLIC_APP_URL
     Значение: https://miss-kurochka.com
     ```
   - Сохраните
   - Перезапустите приложение

3. **Также проверьте `NEXTAUTH_URL`:**
   ```
   ✅ NEXTAUTH_URL=https://miss-kurochka.com
   ```

---

### ШАГ 4: Проверьте sitemap после деплоя (2 минуты)

**Подождите 5-10 минут после завершения деплоя, затем:**

1. **Откройте браузер и перейдите:**
   ```
   https://miss-kurochka.com/sitemap.xml
   ```

2. **Проверьте URL в sitemap:**

   **✅ ПРАВИЛЬНО (успех):**
   ```xml
   <url>
     <loc>https://miss-kurochka.com</loc>
     ...
   </url>
   <url>
     <loc>https://miss-kurochka.com/menu</loc>
     ...
   </url>
   ```

   **❌ НЕПРАВИЛЬНО (нужны действия):**
   ```xml
   <url>
     <loc>http://localhost:3000</loc>  <!-- ❌ -->
     ...
   </url>
   ```

**Если видите localhost:**
- Вернитесь к Шагу 3
- Убедитесь что `NEXT_PUBLIC_APP_URL` установлена правильно
- Перезапустите приложение
- Подождите 5-10 минут
- Повторите проверку

### ШАГ 5: Проверьте robots.txt (1 минута)

### Проблема 2: Sitemap все еще показывает localhost

**Причина:** Переменная `NEXT_PUBLIC_APP_URL` не установлена или неправильная

**Решение:**
1. Timeweb → Переменные окружения
2. Добавьте/исправьте: `NEXT_PUBLIC_APP_URL=https://miss-kurochka.com`
3. Перезапустите приложение
4. Подождите 5-10 минут
5. Проверьте снова

**Решение:**
1. Проверьте что sitemap доступен: `curl https://miss-kurochka.com/sitemap.xml`
2. Убедитесь что в sitemap нет localhost
3. Переотправьте sitemap в GSC
4. Подождите 24-48 часов
