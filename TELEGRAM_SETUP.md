# 🤖 Настройка Telegram для админ-панели

Для входа в админ-панель используется двухфакторная аутентификация через Telegram. Коды подтверждения отправляются в ваш Telegram.

## 📋 Шаги настройки

### 1. Создайте Telegram бота

1. Откройте Telegram и найдите бота **@BotFather**
2. Отправьте команду `/newbot`
3. Введите имя бота (например: `Miss Kurochka Admin Bot`)
4. Введите username бота (например: `misskurochka_admin_bot`)
5. Скопируйте **токен бота** (выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Узнайте свой Telegram User ID

1. Найдите бота **@userinfobot** в Telegram
2. Отправьте ему любое сообщение
3. Скопируйте ваш **User ID** (число, например: `123456789`)

### 3. Начните диалог с вашим ботом

1. Найдите вашего бота по username (например: `@misskurochka_admin_bot`)
2. Нажмите **Start** или отправьте `/start`
3. Это необходимо, чтобы бот мог отправлять вам сообщения

### 4. Добавьте настройки в .env

Откройте файл `.env` и добавьте (или обновите) следующие строки:

```env
# Telegram Bot для админ 2FA
ADMIN_TELEGRAM_BOT_TOKEN="ваш-токен-бота"
ADMIN_TELEGRAM_USER_ID="ваш-user-id"
```

**Пример:**
```env
ADMIN_TELEGRAM_BOT_TOKEN="7969896969:AAGqxqxqxqxqxqxqxqxqxqxqxqxqxqxqxqx"
ADMIN_TELEGRAM_USER_ID="123456789"
```

### 5. Инициализируйте настройки в базе данных

Запустите скрипт для сохранения настроек в базу данных:

```bash
npx tsx scripts/init-telegram-settings.ts
```

Скрипт:
- ✅ Сохранит настройки в базу данных
- ✅ Проверит подключение к боту
- ✅ Отправит тестовое сообщение

### 6. Готово! 🎉

Теперь при входе в админ-панель:
1. Введите email и пароль
2. Получите 6-значный код в Telegram
3. Введите код для завершения входа

## 🔧 Устранение неполадок

### Ошибка: "Telegram не настроен"
- Убедитесь, что вы запустили скрипт `init-telegram-settings.ts`
- Проверьте, что настройки сохранены в таблице `SystemSetting`

### Ошибка: "Не удалось отправить код в Telegram"
- Убедитесь, что вы начали диалог с ботом (отправили /start)
- Проверьте правильность токена бота
- Проверьте правильность User ID

### Код не приходит
- Проверьте, что бот не заблокирован
- Убедитесь, что вы используете правильный User ID
- Проверьте логи сервера на наличие ошибок

## 📝 Дополнительная информация

### Как получить токен бота заново?
1. Откройте @BotFather
2. Отправьте `/mybots`
3. Выберите вашего бота
4. Нажмите **API Token**

### Как изменить настройки?
1. Обновите значения в `.env`
2. Запустите `npx tsx scripts/init-telegram-settings.ts` снова

### Безопасность
- ⚠️ Никогда не публикуйте токен бота
- ⚠️ Не добавляйте `.env` в git
- ✅ Используйте `.env.example` как шаблон
