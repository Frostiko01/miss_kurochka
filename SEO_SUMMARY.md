## 📋 Следующие шаги (после деплоя)

### Шаг 1: Зарегистрируйтесь в Google Search Console

1. Перейдите: https://search.google.com/search-console/
2. Добавьте свой домен
3. Пройдите верификацию (HTML-тег или файл)

### Шаг 2: Обновите код верификации

После получения кода от Google, добавьте в `.env`:

```env
NEXT_PUBLIC_GOOGLE_VERIFICATION="ваш-код-от-google"
```

Затем обновите `app/layout.tsx`:

```typescript
verification: {
  google: process.env.NEXT_PUBLIC_GOOGLE_VERIFICATION,
  yandex: "0575424bed77977e", // уже настроен
},
```

### Шаг 3: Отправьте sitemap в Google

В Google Search Console:
1. Раздел "Карты сайта" (Sitemaps)
2. Введите: `sitemap.xml`
3. Нажмите "Отправить"

### Шаг 4: Обновите контактные данные

В `components/StructuredData.tsx` замените:

```typescript
telephone: '+996-XXX-XXX-XXX'  // ← Замените на реальный
```

На ваш реальный номер:

```typescript
telephone: '+996-555-123-456'
```

И добавьте реальный адрес:

```typescript
address: {
  '@type': 'PostalAddress',
  streetAddress: 'ул. Ленина, 123', // ← Реальный адрес
  addressLocality: 'Бишкек',
  ...
}
```

### Шаг 5: Добавьте ссылки на соцсети

В `components/StructuredData.tsx`:

```typescript
sameAs: [
  'https://www.instagram.com/miss_kurochka_kg',
  'https://www.facebook.com/misskurochka',
  'https://t.me/miss_kurochka',
],
```

## 🆘 Решение проблем

### Логотип всё ещё не отображается?
- Убедитесь, что `public/logo.png` доступен по URL
- Размер логотипа: рекомендуется 500x500px или больше
- Подождите 3-7 дней для переиндексации

### Сайт не индексируется?
- Проверьте статус в Google Search Console → Coverage
- Убедитесь, что верификация пройдена
- Убедитесь, что robots.txt не блокирует индексацию

### Старое описание в Google?
- Обновите метаданные в `app/layout.tsx`
- Запросите повторную индексацию в Google Search Console
- Подождите несколько дней
