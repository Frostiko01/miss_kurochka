## 🐛 Если не работает

### Проблема: Кнопка не отображается

**Причина:** Поле `whatsappNumber` пустое

**Решение:**
```sql
-- Проверить номер
SELECT name, whatsapp_number FROM branches WHERE id = 'id-филиала';

-- Добавить номер
UPDATE branches SET whatsapp_number = '+996700123456' WHERE id = 'id-филиала';
```

---

### Проблема: WhatsApp не открывается

**Причина:** Неправильный формат номера

**Решение:**
- Номер должен содержать только цифры: `996700123456`
- Должен начинаться с кода страны: `996`
- Без пробелов и спецсимволов внутри

---

### Проблема: Текст сообщения не подставляется

**Причина:** Браузер блокирует или WhatsApp не поддерживает

**Решение:**
- Это нормально на некоторых устройствах
- Пользователь может скопировать текст вручную
- Номер всё равно подставляется правильно
