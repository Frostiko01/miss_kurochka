
### Метод 2: Локально с Production DATABASE_URL

1. **Сохраните текущий `.env`:**
   ```bash
   cp .env .env.backup
   ```

2. **Временно замените DATABASE_URL** на production (из Timeweb панели)

3. **Запустите скрипт:**
   ```bash
   npx tsx scripts/set-branch-password.ts
   ```

4. **Верните `.env` обратно:**
   ```bash
   cp .env.backup .env
   ```
