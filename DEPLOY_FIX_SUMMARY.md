## ✅ Решение

### Что было исправлено:

**ДО (не работало):**
```typescript
robotsConfig.rules.forEach(rule => {
  console.log(`Allow: ${rule.allow}`)
  rule.disallow?.forEach(path => {
    console.log(`Disallow: ${path}`)
  })
})
```

**ПОСЛЕ (работает):**
```typescript
// Правильная обработка: rules может быть объектом или массивом
const rules = Array.isArray(robotsConfig.rules) 
  ? robotsConfig.rules 
  : [robotsConfig.rules]

rules.forEach((rule: any) => {
  if (rule.allow) {
    const allows = Array.isArray(rule.allow) ? rule.allow : [rule.allow]
    allows.forEach((path: string) => console.log(`Allow: ${path}`))
  }
  if (rule.disallow) {
    const disallows = Array.isArray(rule.disallow) ? rule.disallow : [rule.disallow]
    disallows.forEach((path: string) => console.log(`Disallow: ${path}`))
  }
})
```

## 💡 Известные проблемы

### Turbopack (Next.js 16):

Если используется Turbopack, могут быть проблемы со шрифтами Google Fonts:

```
Error: Can't resolve '@vercel/turbopack-next/internal/font/google/font'
```

**Решение:** Используйте стандартный webpack:
```bash
TURBOPACK=0 npm run build
```

Или в `next.config.mjs`:
```javascript
export default {
  experimental: {
    turbopack: false
  }
}
```
