## 🔄 Процесс деплоя

```
1. Git Push
   ↓
2. Timeweb получает webhook от GitHub/GitLab
   ↓
3. Клонирование репозитория
   ↓
4. Сборка Docker-образа (Dockerfile)
   - Установка зависимостей
   - Генерация Prisma Client
   - Сборка Next.js приложения
   ↓
5. Создание Docker-контейнера
   - Загрузка переменных окружения из Timeweb
   - Запуск приложения на порту 3000
   ↓
6. Настройка Nginx
   - Проксирование домена на контейнер
   - Выпуск/обновление SSL сертификата
   ↓
7. Приложение доступно по домену
```

## 🔐 Безопасность

### Что защищено:
- ✅ Переменные окружения не в репозитории
- ✅ Приватные ключи передаются через Timeweb
- ✅ Контейнер работает от непривилегированного пользователя
- ✅ SSL сертификат автоматически
- ✅ База данных вне контейнера

### Рекомендации:
- 🔒 Используйте сильный NEXTAUTH_SECRET (минимум 32 символа)
- 🔒 Регулярно обновляйте зависимости
- 🔒 Настройте резервное копирование базы данных
- 🔒 Мониторьте логи на наличие ошибок
- 🔒 Используйте разные ключи для dev и production

## 📈 Производительность

### Оптимизации в Dockerfile:
- Multi-stage build (уменьшает размер образа на 70%)
- Alpine Linux (легковесный базовый образ)
- Next.js standalone mode (минимальные зависимости)
- Кэширование слоев Docker (быстрая пересборка)

### Ожидаемые показатели:
- **Размер образа:** ~200-300 MB
- **Время сборки:** 5-10 минут (первая), 2-3 минуты (последующие)
- **Время запуска:** 5-10 секунд
- **Потребление RAM:** ~200-400 MB
- **Время ответа API:** <100ms (зависит от БД)

## 🎓 Что нужно знать

### Особенности Timeweb App Platform:
1. **Ephemeral storage** - данные в контейнере не сохраняются между деплоями
2. **Автоматический перезапуск** - при git push создается новый контейнер
3. **Переменные окружения** - передаются через панель управления
4. **Логи** - доступны в реальном времени в панели
5. **SSL** - выпускается автоматически для всех доменов

### Что НЕ нужно делать:
- ❌ Хранить файлы в контейнере (используйте S3)
- ❌ Использовать SQLite (используйте PostgreSQL)
- ❌ Коммитить .env файлы в Git
- ❌ Хардкодить секреты в коде
- ❌ Использовать localhost для внешних сервисов
