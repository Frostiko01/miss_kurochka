## 🔧 Почему автодеплой может не работать

### Причина 1: Автодеплой не включен

**Как проверить и включить:**

1. Войдите в панель управления Timeweb Cloud
2. Перейдите в **App Platform**
3. Выберите ваше приложение
4. Перейдите в раздел **"Настройки"** или **"Settings"**
5. Найдите секцию **"Автодеплой"** или **"Auto Deploy"**
6. Убедитесь, что переключатель включен (зеленый)
7. Проверьте, что выбрана правильная ветка: `main`

### Причина 2: Неправильно указан репозиторий

**Как проверить:**

1. В настройках приложения найдите секцию **"Репозиторий"**
2. Убедитесь, что указан правильный репозиторий:
   ```
   https://github.com/Frostiko01/miss_kurochka.git
   ```
3. Проверьте, что выбрана ветка: `main`

### Причина 3: Нет прав доступа к репозиторию

**Как проверить:**

1. Перейдите в **"Настройки"** → **"GitHub Integration"**
2. Убедитесь, что Timeweb имеет доступ к вашему репозиторию
3. Если доступа нет — переподключите GitHub аккаунт:
   - Нажмите **"Reconnect GitHub"**
   - Авторизуйте Timeweb App Platform
   - Выберите нужный репозиторий

### Причина 4: Webhook не настроен

**Как проверить в GitHub:**

1. Откройте ваш репозиторий на GitHub:
   ```
   https://github.com/Frostiko01/miss_kurochka
   ```
2. Перейдите в **Settings** → **Webhooks**
3. Найдите webhook от Timeweb (должен быть URL типа `*.timeweb.cloud/webhook`)
4. Проверьте статус:
   - ✅ Зеленая галочка = работает
   - ❌ Красный крестик = проблема

**Если webhook отсутствует:**
1. Вернитесь в Timeweb App Platform
2. Отключите и снова включите автодеплой
3. Это должно автоматически создать webhook

### Причина 5: Ошибка при предыдущем деплое

**Как проверить:**

1. В Timeweb App Platform откройте раздел **"Деплои"** или **"Deployments"**
2. Посмотрите на статус последнего деплоя:
   - ✅ Success (зеленый) = всё хорошо
   - ❌ Failed (красный) = ошибка
   - ⏳ In Progress = деплой идёт прямо сейчас
3. Если статус "Failed", откройте логи и посмотрите ошибку

## 🚀 Ручной запуск деплоя

Если автодеплой не работает, запустите деплой вручную:

### Вариант 1: Через интерфейс Timeweb

1. Откройте ваше приложение в Timeweb App Platform
2. Найдите кнопку **"Deploy"** или **"Redeploy"**
3. Нажмите на неё
4. Подтвердите деплой

### Вариант 2: Пересоздание деплоя

1. В разделе **"Деплои"** нажмите на последний деплой
2. Найдите кнопку **"Rebuild"** или **"Restart"**
3. Подтвердите пересборку

## 📊 Мониторинг процесса деплоя

После запуска деплоя (автоматического или ручного):

### 1. Проверьте статус
```
Timeweb App Platform → Ваше приложение → Deployments
```

Увидите:
- ⏳ **Building** - идёт сборка Docker образа
- ⏳ **Deploying** - идёт деплой
- ✅ **Running** - приложение работает
- ❌ **Failed** - ошибка (смотрите логи)

### 2. Откройте логи сборки
```
Timeweb App Platform → Ваше приложение → Logs → Build Logs
```

Должно быть примерно так:
```
✓ Cloning repository...
✓ Installing dependencies...
✓ Generating Prisma Client...
✓ Building Next.js...
✓ Creating Docker image...
✓ Starting container...
✓ Application is running on port 3000
```

### 3. Проверьте логи приложения
```
Timeweb App Platform → Ваше приложение → Logs → Application Logs
```

Убедитесь, что нет ошибок при запуске.

## ⏱️ Сколько ждать?

Типичное время деплоя:
- **Сборка**: 3-8 минут (зависит от размера проекта)
- **Деплой**: 1-2 минуты
- **Итого**: 5-10 минут

После push в GitHub:
1. **0-1 минута** - Webhook срабатывает, деплой запускается
2. **1-8 минут** - Идёт сборка
3. **8-10 минут** - Деплой завершён, приложение перезапущено

4. Войдите снова
5. Корзина должна быть пустой

## 🐛 Решение частых проблем

### "Деплой не запускается совсем"

**Решение:**
1. Проверьте, что автодеплой включен (см. выше)
2. Проверьте webhook в GitHub Settings
3. Попробуйте запустить деплой вручную
4. Проверьте, что репозиторий публичный или Timeweb имеет доступ

### "Деплой застрял в 'Building'"

**Решение:**
1. Подождите до 15 минут
2. Если дольше - отмените и запустите заново
3. Проверьте логи сборки на ошибки

### "Деплой падает с ошибкой"

**Решение:**
1. Откройте логи сборки
2. Найдите ошибку (обычно в конце)
3. Исправьте ошибку в коде
4. Сделайте commit и push
5. Деплой запустится снова

### "Изменения не применяются"

**Возможные причины:**
1. **Кеш браузера** - очистите кеш (Ctrl+Shift+R)
2. **CDN кеш** - подождите 5-10 минут
3. **Старый контейнер** - перезапустите приложение в Timeweb
4. **Неправильная ветка** - проверьте, что деплоится ветка `main`
