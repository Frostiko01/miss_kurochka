## 🔗 Техническая реализация

### Функция генерации ссылки:

```typescript
function getWhatsAppLink() {
  if (!order?.branch.phone) return '#'
  
  // Очищаем номер: +996 700 12-34-56 → 996700123456
  const cleanNumber = order.branch.phone.replace(/\D/g, '')
  
  // Формируем текст
  let message = `Здравствуйте.\n\nУ меня вопрос по заказу №${order.orderNumber}.`
  
  if (order.orderType === 'delivery' && order.deliveryAddress) {
    message += `\n\nАдрес доставки: ${order.deliveryAddress.addressLine}`
    if (order.deliveryAddress.apartment) {
      message += `, кв. ${order.deliveryAddress.apartment}`
    }
  }
  
  message += `\n\nФилиал: ${order.branch.name}\n\nСпасибо.`
  
  // URL-encode
  const encodedMessage = encodeURIComponent(message)
  
  return `https://wa.me/${cleanNumber}?text=${encodedMessage}`
}
```

## 📞 Часто задаваемые вопросы

### Q: Кнопка не отображается

**A:** Проверьте что у филиала есть номер телефона:
```sql
SELECT name, phone FROM branches;
```

Если `phone` пустой или NULL → добавьте номер через админ-панель.

---

### Q: Открывается неправильный номер

**A:** Проверьте что номер в базе данных правильный:
```sql
SELECT name, phone FROM branches WHERE id = 'id-филиала';
```

Исправьте номер если он неправильный.

---

### Q: Можно ли использовать разные номера для звонков и WhatsApp?

**A:** В текущей реализации - нет. Используется один номер (`phone`) и для звонков, и для WhatsApp.

Если нужны разные номера:
1. Добавьте поле `whatsapp_number` в схему (как было раньше)
2. Измените код чтобы использовать `whatsappNumber ?? phone`

---

### Q: Текст сообщения не подставляется на iOS

**A:** Это ограничение iOS/WhatsApp. Номер подставляется всегда, а текст - на усмотрение WhatsApp.

На Android текст подставляется стабильнее.

---

### Q: Как изменить текст сообщения?

**A:** Отредактируйте функцию `getWhatsAppLink()` в файлах:
- `app/orders/[id]/page.tsx`
- `app/orders/[id]/receipt/page.tsx`

Измените строку:
```typescript
let message = `Здравствуйте.\n\nУ меня вопрос по заказу №${order.orderNumber}.`
```
