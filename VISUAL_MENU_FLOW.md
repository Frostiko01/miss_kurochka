## 🔄 Процесс добавления в корзину

### Обычное блюдо / Мини-комбо:

```
Клик на карточку
      ↓
Есть опции? (размеры/модификаторы/специи)
      ↓
    ДА → Открыть модальное окно
      ↓  - Выбрать размер
      ↓  - Выбрать модификаторы
      ↓  - Выбрать специи
      ↓  [Добавить в корзину]
      ↓
    НЕТ → Сразу добавить
      ↓
POST /api/cart
{
  menuItemId: "...",
  quantity: 1,
  sizeId: "...",
  modifiers: [...],
  spices: [...]
}
      ↓
Обновить счетчик корзины
```

### Большое комбо:

```
Клик на карточку комбо
      ↓
POST /api/cart
{
  comboOfferId: "...",
  quantity: 1
}
      ↓
Обновить счетчик корзины
```

## 📈 Статистика и аналитика

### Популярность блюд:

```sql
-- Топ блюд по количеству заказов
SELECT 
  mi.name,
  COUNT(oi.id) as order_count,
  SUM(oi.quantity) as total_quantity
FROM menu_items mi
JOIN order_items oi ON oi.menu_item_id = mi.id
GROUP BY mi.id
ORDER BY order_count DESC
LIMIT 6
```

### Эффективность комбо:

```sql
-- Статистика по комбо
SELECT 
  co.name,
  COUNT(oi.id) as order_count,
  SUM(oi.quantity) as total_quantity,
  SUM(oi.price * oi.quantity) as revenue
FROM combo_offers co
JOIN order_items oi ON oi.combo_offer_id = co.id
GROUP BY co.id
ORDER BY revenue DESC
```

## 🎯 Бизнес-логика

### Когда создавать мини-комбо:

✅ **Используйте мини-комбо если:**
- Набор из 2-3 позиций
- Нужны варианты (размеры, добавки)
- Должно быть в общем меню
- Цена зависит от выбора опций
- Пример: "Комбо Чикен" (бургер + картофель, можно выбрать размер)

### Когда создавать большое комбо:

✅ **Используйте большое комбо если:**
- Набор из 4+ позиций
- Фиксированный состав
- Специальная акционная цена
- Должно выделяться на главной
- Показывать экономию (старая цена)
- Пример: "Семейное комбо" (2 бургера + 2 картофеля + 4 напитка)

## 🔧 Админ-панель - Управление

### Создание обычного блюда:
```
/admin/menu → [+ Создать блюдо]
├─ Выбрать категорию: "Бургеры" (type: regular)
├─ Название: "Бургер Классик"
├─ Описание, фото
├─ Размеры: [Стандарт: 250 сом, Большой: 320 сом]
├─ Модификаторы: [Сыр +30, Бекон +50]
└─ [Сохранить]
```

### Создание мини-комбо:
```
/admin/categories → [+ Создать категорию]
├─ Название: "Мини-комбо"
├─ Тип: mini_combo
└─ [Сохранить]

/admin/menu → [+ Создать блюдо]
├─ Выбрать категорию: "Мини-комбо"
├─ Название: "Комбо Чикен"
├─ Описание: "Бургер + картофель"
├─ Размеры: [Стандарт: 350 сом, Большой: 420 сом]
└─ [Сохранить]
```

### Создание большого комбо:
```
/admin/combo-offers → [+ Создать комбо]
├─ Название: "Семейное комбо"
├─ Описание: "Идеально для семьи из 4 человек"
├─ Цена: 1200 сом
├─ Старая цена: 1500 сом (показать скидку -20%)
├─ Фото
├─ Состав:
│  ├─ Бургер Классик × 2
│  ├─ Картофель фри × 2
│  └─ Кола 0.5л × 4
└─ [Сохранить]
```
