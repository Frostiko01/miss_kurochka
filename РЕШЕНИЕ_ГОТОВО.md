## 📦 Что было сделано

### 1. **Исправлен звук на мобильных устройствах** 🔊

**Проблема:**  
Звук уведомлений не воспроизводился автоматически на смартфонах из-за политики браузеров (User Gesture Policy).

**Решение:**  
Реализована система разблокировки аудио:
- При первом клике/тапе инициализируется `AudioContext`
- Воспроизводится беззвучный буфер для разблокировки
- Предзагружается реальный звук
- После этого `.play()` работает автоматически

**Файл:** `components/branch/OrderSoundNotification.tsx`

**Результат:**  
✅ Работает на iOS Safari  
✅ Работает на Android Chrome  
✅ Работает в PWA режиме  
✅ Мгновенное воспроизведение без задержек

## 🐛 Известные ограничения

### iOS Safari:
- Звук не работает если переключатель "Без звука" включен (ограничение iOS)
- Требует обязательный клик/тап после открытия

### Android Chrome:
- При очень низком заряде (<10%) звук может не воспроизводиться
- Может запросить разрешение через UI браузера

### Service Worker:
- Обновление может занять до 24 часов на некоторых устройствах
- В режиме Инкогнито не кэширует данные

## 📞 Если что-то не работает

### Звук:
1. Проверьте что пользователь **кликнул** после входа
2. Откройте консоль (F12) → должен быть лог: `✅ Аудио разблокировано`
3. Проверьте что звуковой файл доступен: `https://домен.com/uvedomlenie.mp3`
4. На iOS: отключите переключатель "Без звука"

### Номер заказа:
1. Пересоберите: `npm run build`
2. Очистите кэш браузера (Ctrl+Shift+Del)
3. Или откройте в режиме Инкогнито

### Service Worker:
1. DevTools → Application → Service Workers
2. Поставьте галочку "Update on reload"
3. Или нажмите "Unregister" и перезагрузите
